# Tic Tac Toe

[**Live Demo**](https://naveenairani.github.io/tic-tac-toe/)

A simple Tic Tac Toe game built with HTML, CSS, and JavaScript.

## Getting Started

Follow these steps to get the project running locally:

### 1. Clone the Repository

Open your terminal and run:

```bash
git clone https://github.com/naveenairani/tic-tac-toe.git
```

### 2. Open the Game

Navigate into the cloned directory and click on the `index.html` file to open it in your web browser.

Alternatively, you can visit the Live Demo by clicking on the link above: [https://naveenairani.github.io/tic-tac-toe/](https://naveenairani.github.io/tic-tac-toe/).

## About the Game

Tic Tac Toe is a classic two-player game. This project demonstrates basic web development concepts along with interactive game logic.

## How to Play

- **Gameplay:** Two players take turns marking a cell in a 3×3 grid.
- **Win Condition:** The first player to align three marks (horizontally, vertically, or diagonally) wins.
- **Draw:** If all cells are filled without a winning combination, the game is declared a draw.
- **Restart:** Click the **Restart Game** button to reset the board at any time.

## Project Structure

- `index.html` - The main HTML file containing the game layout.
- `style.css` - The CSS file responsible for styling the game.
- `script.js` - The JavaScript file handling the game logic and interactivity.
